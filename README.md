# MPXDownloader

Aplicativo de DXT para baixar áudio MP3 e vídeo MP4.

## Instalação no Windows

1. Baixe **MPXDownloader-Windows.zip** em https://github.com/dxrkths/MPXDownloader-Releases/releases/latest.
2. Extraia a pasta inteira.
3. Abra **MPXDownloader.exe**. Mantenha deno.exe, ffmpeg.exe e ffprobe.exe na mesma pasta.
4. Cole um link por linha, selecione o formato, a qualidade e uma pasta de destino.

Ao abrir, o programa consulta novas versões e mostra uma descrição das novidades. Use o botão para acessar a versão no GitHub. Feche o aplicativo e extraia o novo ZIP em outra pasta para atualizar.

Falhas ficam registradas em `%LOCALAPPDATA%\MPXDownloader\app.log` e aparecem na tela. Vídeos privados, removidos ou restritos podem não estar disponíveis. Baixe apenas conteúdo que você tem autorização para baixar.

O código-fonte do aplicativo é privado. Este repositório distribui somente os pacotes compilados e as notas das versões.
